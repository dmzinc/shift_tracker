ShiftMate installable web app

Upload the contents of this folder together to an HTTPS host (Netlify, GitHub Pages, etc.). Open the resulting URL on a phone. On iPhone Safari choose Share > Add to Home Screen. On Android Chrome choose menu > Install app or Add to Home screen.

Important: Notes live in browser storage and do not automatically sync across devices or origins. Export a JSON backup from the old version and restore it on the hosted version. Background notifications cannot be guaranteed by this PWA while closed; reliable push notifications require a backend and push subscription. Excel importing requires an internet connection for the external XLSX library.
