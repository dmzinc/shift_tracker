Install ShiftMate on your phone

Open this hosted web app in Safari (iPhone) or Chrome (Android), then add it to your home screen for an app-like experience.

On iPhone: tap Share → Add to Home Screen. On Android: open Chrome menu → Install app or Add to Home screen. Installation requires HTTPS hosting; opening this HTML directly from Files will not install a PWA.

Daily encouragement before shifts

Receive a positive affirmation 30 minutes before each shift with a confirmed start time.

Checking notification support…

For reminders, leave ShiftMate running in the foreground near shift time. Home-screen installation alone cannot schedule notifications while the app is closed or the phone is asleep. System notifications require permission and HTTPS. Shifts without confirmed start times are skipped.
